# Reproducible analysis pipeline

Run the complete workflow from the `group project` directory with:

```powershell
python scripts/06_run_pipeline_and_validate.py
```

The local system `python` is used because it contains pandas, openpyxl,
Matplotlib and Pillow. The numbered stages are:

1. `01_clean_and_match_inputs.py` — cleans `raw.csv`, validates the 74- and
   20-country lists, resolves country-name aliases, and extracts the CPI
   2024–2035 adaptation and conditionality fields.
2. `02_compute_2035_allocations.py` — aggregates both coalition definitions
   and calculates equal-per-capita, historical-responsibility and
   ability-to-pay allowances under a fixed 50% world budget.
3. `03_compute_adaptation_finance.py` — summarizes reported adaptation need,
   constructs a clearly labelled external-support proxy, and applies the
   supplied loan/grant country classification.
4. `04_create_charts.py` — writes eight source-labelled PNG charts to
   `../charts`.
5. The two English memoranda in `../output`—the 74-country LDC+AOSIS case and
   the supplied Global South coalition result—are authored directly from the
   verified results; they are not generated by a script.
6. `06_run_pipeline_and_validate.py` — runs stages 1–4 and checks roster
   counts, budget conservation, key results, chart dimensions and the manually
   authored memoranda.

Files in `asset/` are treated as immutable inputs. Generated CSV and Markdown
files go to `output/`; figures go to `charts/`.
